# Engineering Handbook

A curated collection of engineering notes, explanations, implementation guides, and interview preparation materials.

This repository serves as my personal knowledge base, documenting concepts I learn throughout my software engineering journey. The goal is not only to take notes but also to deeply understand topics by explaining them from first principles with practical examples and real-world use cases.

> **Work in Progress:** This handbook is continuously evolving as I learn new technologies and revisit existing topics.

---

## 📚 Topics

The repository currently covers (or will cover) topics including:

- System Design
- Database
- Python
- Django
- JavaScript
- Next.js
- AI Engineering
- Large Language Models (LLMs)
- Retrieval-Augmented Generation (RAG)
- Docker
- DevOps
- Networking
